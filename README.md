# KeyFrame

## Solo Project

## Tier Selection

**Tier 1** — A focused prototype for detecting piano key presses from video.

## Problem Statement

Identifying which piano key is being played from video can be difficult manually. KeyFrame aims to automatically detect piano key presses and identify the corresponding key.

## Solution Overview

KeyFrame will use computer vision to analyze piano video and detect key presses. The prototype will focus on a limited number of piano keys.

## Technical Approach

* Python
* OpenCV
* Computer vision
* Video-based key detection

## Data Plan

* **Source:** Project-generated piano video recordings
* **Size:** Small labeled dataset for the prototype
* **Labels:** Piano key pressed
* **Public dataset:** Not applicable

## Success Metrics

* **Primary:** Key-detection accuracy — target of **90% or higher**
* **Secondary:** Reliable detection of individual key presses and correct key identification

## Top Risks & Plan B

| Risk                       | Plan B                                      |
| -------------------------- | ------------------------------------------- |
| Poor lighting              | Use controlled lighting                     |
| Camera movement            | Use a fixed camera                          |
| Key detection is difficult | Reduce the number of target keys            |
| Accuracy is too low        | Adjust detection method and test conditions |
